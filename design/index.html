Three directions for the BFR Deck home screen

Each frame is the deck at its real width, 560 px, docked beside BlueStacks. Same content in all three: your squad, level and currencies, the next resets, this week's featured units and a banner. Only the treatment differs. Mix and match is fine: say which parts you like.

A · Stage

Idea: the leader's full illustration is the hero; the squad stands in front of it like the game's title screen. Big, quiet, pretty. Bottom icon bar like the game's own menu.

  • Best when you mostly glance at it between fights.
  • Least information per screen; the data lives one scroll down.
  • Sprites can replace the thumbnails once the animations are in.

B · Command

Idea: a tile grid you scan, not read. Every number that can change colour does: reset timers, pull odds, session length. Closest to how overlay tools for competitive games lay things out.

  • Best if you want everything on one screen with no scrolling.
  • Least "Brave Frontier": it is a dashboard first.
  • Easiest to extend: a new feature is a new tile.

C · Codex

Idea: borrow the game's own menu language: gold corner brackets, engraved headings, dark leather. An icon rail on the left instead of a text tab row, so the page is wider. One unit is always in focus, like the unit book.

  • Best for browsing units and planning; feels like part of the game.
  • Most work to keep consistent; every panel needs the frame treatment.
  • The rail frees 30 px of height and makes room for a sixth nav item later.
